### 2. Create Feature Design Document

After the user approves Requirements, create the minimum sufficient implementation-ready design. Refer to requirement IDs instead of restating them, record only decisions that affect implementation, and research only unresolved facts that materially change those decisions.

Use the core and conditional sections defined by `design-templete.md` and the soft length target in `SKILL.md`.

Write all user-visible prose in the generated `design.md` in Chinese, including the overview, design decisions, research findings, testing strategy, and explanatory text under each section. Keep the required and selected conditional section names exactly as listed in `design-templete.md` in English as structural keywords. Preserve project-specific names, technical terms, code identifiers, filenames, URLs, Markdown syntax, and Mermaid syntax when necessary.
